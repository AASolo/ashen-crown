# Ashen Crown: Echoes of the Hollow Sun

Пепельный Венец: Эхо Пустого Солнца. Прототип изометрической тёмно-фэнтезийной ARPG на **TypeScript + Vite + Phaser 3**.

## Быстрый старт

**Играть в браузере:** https://aasolo.github.io/ashen-crown/ (собирается и обновляется сама после каждого слияния в main, см. `.github/workflows/pages.yml`).

**Без установки:** `npm run build:single` собирает всю игру в один файл `dist-single/index.html`, его можно открыть в браузере офлайн.

**Для разработки:**
```bash
npm install
npm run dev          # http://localhost:5173 с горячей перезагрузкой
npm run build        # проверка типов + сборка в dist/
npm run build:single # вся игра одним HTML-файлом в dist-single/index.html
npm run preview      # локальный сервер для dist/
```

- Галерея ассетов: `http://localhost:5173/?gallery` или пункт меню «Галерея ассетов».
- Дымовой тест (нужен Playwright): `node tools/smoke.cjs` при запущенном `npm run preview -- --port 5173`.

## Что есть в прототипе
- Пролог «Пепелище у Ковен-Гейта»: старт на поверхности, лагерь выживших, диалоги, журнал заданий (J), 5 заданий акта I.
- Поверхность из тайлсета FLARE: лес, срубы, башня-мельница, пруд с мостками; северная музыка Wyrmsun.
- 4 класса (Пепельный Клинок, Пепельная Ведьма, Костолом, Тень Пустоты): базовая атака + 3 навыка, ранги 1–5, по 3 таланта.
- Бесконечные Разломы: этажи чередуют Пепельные Пустоши (клеточный автомат) и Затонувшие Катакомбы (BSP). Тайники за треснувшими стенами, ловушки, сундуки, модификаторы этажа.
- 4 вида врагов + элиты с 5 аффиксами. Босс «Глашатай Пустого Солнца»: 3 фазы, телеграфы, субтитры.
- Лут: 6 редкостей, аффиксы с согласованием рода, 5 легендарных свойств, сет на 6 частей. Сумка с перетаскиванием, сравнением, продажей, разбором и улучшением.
- Уровни до 60, золото и Пепельные осколки, 4 сложности, автосохранение.
- Свет и тьма, частицы, процедурный звук, мини-карта и карта этажа.
- Управление: мышь и клавиатура (2 схемы), геймпад, сенсорный экран. Масштаб UI, режим дальтонизма, настройка тряски, субтитры, чёткость на 4K.

## Управление
| | Классика | WASD |
|---|---|---|
| Движение | ЛКМ по земле (удерживать) | WASD |
| Атака | ЛКМ по врагу, Shift+ЛКМ на месте | ЛКМ |
| Навыки | ПКМ / Q, W, E | Q, E, R |
| Уклонение | Пробел | Пробел |
| Зелье | R | F |
| Сумка / Навыки / Карта / Пауза | I, K, M, Esc | так же |

Геймпад: стик — движение, A — атака, X/Y/B — навыки, RB — уклонение, LB — зелье. На телефоне: джойстик слева, кнопки справа, автоприцел.

## Структура
```
src/core      — изометрия, ГСЧ, шина событий, звук
src/data      — классы, навыки, враги, предметы, характеристики (чистые данные)
src/systems   — ввод, бой, навыки, лут, герой, сохранения, настройки, эффекты
src/world     — генерация подземелий, уровень, поиск пути
src/entities  — герой, враги, босс, снаряды и зоны
src/art       — процедурная графика (Canvas 2D)
src/scenes    — Boot, Menu, Game, UI, Gallery
art/          — PNG-экспорт процедурного арта
```
Комментарии в коде — на русском.
